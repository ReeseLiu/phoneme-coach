展示模式操作

如何進入展示模式

在主畫面上方的「句子顯示模式」列，點擊 展示 按鈕即可進入全螢幕沉浸式跟讀練習介面。 點擊左上角的 ↩ 按鈕可返回精簡模式。

工具列控制項

IPA / KK / 專利注音 切換音標顯示系統。「專利注音」會將每個音節分解成 C1／V／C2 三列顯示。
0.5x … 1.5x 調整播放速度。建議練習時先用 0.75x，熟練後逐漸提升至 1x。
音標 切換音標行顯示／隱藏。隱藏後可測試自己能否不看提示跟讀。
語調 切換語調行（輕重音標記）顯示／隱藏。
⟲ 開啟／關閉單句循環播放。開啟時會在同一句反覆播放直到手動切換。
− 100% ＋ 縮小／放大整體音標顯示比例，可依螢幕大小調整。
s 欄位 循環間隔秒數（每次播放結束後停頓多久再重播）。
# 欄位 循環總次數。留空表示無限循環。設定範圍循環時，此數字代表「整段範圍重複的輪數」。

主要播放控制

舞台中央有三個大按鈕：

  • ◀ — 跳到上一句
  • ▶ — 播放／暫停目前句子
  • ▶︎ — 跳到下一句

播放全部 / 播放範圍

點擊「播放全部」按鈕，將從目前句子依序連續播放到最後一句， 每句之間使用「s 欄位」設定的間隔。再次點擊可停止。 適合整段課文連續跟讀練習。

若已透過「設定範圍」指定起訖句，按鈕文字會變為 「播放範圍 ⟲」，點擊後只在該範圍內循環播放， 以「# 欄位」設定的次數為區塊輪數（留空則無限循環）。 狀態條會顯示目前範圍與第幾輪（例如「🔁 範圍 8–13 · 第 2/3 輪」）。 點擊狀態條右側的 × 可隨時清除範圍設定。

起訖偏移微調與完成標記

偏移按鈕位於工具列右側，每句可單獨調整播放起點與終點，每次移動 0.1 秒（範圍 ±5 秒）：

  • 起 − / 起 ＋ — 往前／往後移動播放起點
  • 訖 − / 訖 ＋ — 往前／往後移動播放終點

偏移值會自動儲存，下次載入相同課程時保留。 若想微調切去不需要的靜音片段，或讓句子邊界更清晰，可使用此功能。

同一列最右側的 完成 按鈕（✓ 已完成）可用來標記目前句子的練習進度， 方便追蹤哪些句子已練過、哪些還沒練。完成狀態會同步顯示在下方逐字稿及課程下拉選單中。

專利注音編輯

什麼是 C1 / V / C2？

選擇「專利注音」顯示系統時，每個音節會被拆解成三層垂直排列：

  • C1（聲母 Onset）— 音節起始的子音，例如 b、t、ʃ
  • V（韻核 Vowel Nucleus）— 音節的母音核心，以紅色顯示
  • C2（韻尾 Coda）— 音節末尾的子音，例如 n、d、k

每個單字在展示模式下以直欄呈現，三列依序對應 C1、V、C2。

如何切換到專利注音

在展示模式的工具列下拉選單，或側邊欄「顯示系統」選單中，選擇 「專利注音」即可切換。切換後音標行會立即更新為三列格式。

管道符號 | 的作用

在精簡或詳細模式的編輯欄位中輸入 |（管道符號）， 可手動指定音節分界，讓一個單字在展示模式顯示為多個獨立欄位。

使用注意

  • | 可放在 token 之間的任何位置，也可使用多個分隔符號來建立三欄以上。
  • 修改後儲存，展示模式會立即反映新的欄位版面。
  • | 僅在「專利注音」顯示系統下有效；切換到 IPA 或 KK 時不影響顯示。
  • 手動設定的欄位分界儲存在每個單字的顯示編輯資料中，下次開啟可自動還原。

如何保留修改

自動儲存機制

對線上課程（Remote Lesson）的所有修改，包含：

  • Gold IPA 內容
  • 各顯示系統（IPA / KK / 專利注音）的顯示編輯
  • 起訖偏移微調
  • 單字備註

都會在每次修改後自動儲存到瀏覽器的 localStorage。 下次在同一瀏覽器載入相同課程時，修改會自動還原， 不需要手動按儲存。

瀏覽器限制

以下情況會導致修改遺失，請注意：

  • 換不同的瀏覽器或裝置（修改只存在目前的瀏覽器中）
  • 清除瀏覽器快取或 localStorage
  • 使用無痕模式（隱私視窗）——關閉視窗後即遺失
  • localStorage 空間不足時（較少見，但容量有限）

匯出備份

建議定期點擊「下載 lesson JSON」按鈕，匯出包含所有修改的完整課程資料， 儲存到電腦中作為備份。這是保護修改資料最可靠的方式。

匯入還原

若需要在其他瀏覽器或裝置上還原修改，可使用側邊欄的 「本機課程（覆蓋）」功能：

  1. 選取先前下載的 lesson JSON 所在資料夾（需包含 lesson.json 與 audio/）
  2. 系統會載入本機資料並覆蓋線上課程的顯示
  3. 所有修改將從 JSON 檔案中完整還原

清除本機編輯

若想把課程還原到原始狀態，可點擊側邊欄線上課程區塊中的 「清除本機編輯」按鈕，清除 localStorage 中目前課程的所有暫存修改。
